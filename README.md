# Ethylene

Fabric client-side optimization mod for Minecraft 1.20.6 / Fabric with an FPS-focused chunk LOD and mob density system.

## Features

### 1. Chunk LOD
- Keep full detail in the inner rings around the player.
- Reduce rendered texel detail progressively in the outer rings.
- Use configuration values for `fullDetailChunks`, `lodChunkStep`, and `lodReduction`.

### 2. Mob density optimization
- Blur nearby mobs when they are too dense.
- Reduce animation / movement when the mob count exceeds the threshold.
- Tune `mobBlurPercent`, `mobDensityThreshold`, `mobDensityRadius`, and `reduceMobMotion`.

## Build status

This repository is structured as a real Fabric mod and is ready for a standard Fabric build pipeline using Gradle + Loom.

### Required runtime
- Java 21 (recommended stable Fabric toolchain)
- Gradle wrapper generated by Loom
- Fabric Loader / Fabric API matching Minecraft 1.20.6

### Build

```bash
./gradlew clean build
```

If your local machine is on JDK 25, you can raise the `release` and `sourceCompatibility` values to `VERSION_25` after testing.

## Config file

The config is stored under:

```text
.minecraft/config/ethylene.json
```

Default values:

```json
{
  "lodEnabled": true,
  "fullDetailChunks": 2,
  "lodChunkStep": 1.0,
  "lodReduction": 1.0,
  "mobBlurEnabled": true,
  "mobBlurPercent": 50,
  "mobDensityThreshold": 40,
  "mobDensityRadius": 32,
  "reduceMobMotion": true
}
```
